# A Day of One-Line Pitches: Make.fun Entry

## The Pitch
> Tell me your app idea over coffee, and I'll build a quick working draft you can easily tweak or scrap in just a few minutes, so there's really nothing to lose by trying.

## Character Count
The pitch sentence is **169 characters** long (well within the 240-character limit).

## What the Pitch Does
- **Conversational Tone:** Frames the idea naturally over coffee like one friend talking to another.
- **Concrete Action:** Offers to build a quick working draft that can be immediately seen and interacted with.
- **Low-Risk Reason:** Gives a small, true reason to say yes now (tweak or scrap in minutes, nothing to lose).
- **Grounded & Truthful:** Avoids overpromising or sounding like generic product copy.

## How to Run
Run the TypeScript program using Node.js (with TypeScript support enabled or transpiled):
```bash
node --import tsx main.ts
```
Or set `MAKEFUN_OUTPUT_DIR` to specify a custom output directory:
```bash
MAKEFUN_OUTPUT_DIR=./my-output node --import tsx main.ts
```
